# 2D Platformer Example

Import this Game project from Project Examples. Open Tile Map to edit the
floor and player spawn, then run it with the Canvas2D camera. The project
contains its own editable scene, map, actor texture, animation, input, audio
and GUI. Open the project input profile to see the current keyboard and
controller bindings.

The build uses the same-edition Epoch source. The generated Library and
runtime artifacts are recreated by Build.
