Epoch active inventory
======================

Public headers
- `Engine/include/engine.hpp`
- `Engine/include/engine.config.hpp`
- `Engine/include/epoch.config.hpp`
- supporting API/common headers under `Engine/include/`

Primary module families
- `core.*`, `context.*`, `platform.*`, `render.*`, `perf.*`, `updater.*` spine/runtime ownership
- `engine.visuals` central visual profile for frame clears, scene clears,
  object/selection colors, look markers, and editor opacity parity
- `ai.*` OS-model selection, model-asset metadata, evidence packets, eval gates,
  and MCP/tool-harness planning surfaces
- `voxel.*` core multi-informational voxel field and trace/query contracts
- `forest.factory` deterministic built-in Forest Factory contracts; project assets
  remain opt-in through package activation
- `package.registry` source-owned package descriptors for runtime-minis,
  core opt-in packages, and research/downloadable package candidates
- `opengl.*`, `sdl.*`, `raylib.*`, `sfml.*`, `software.*`, `vulkan.*`, `noop.context` backend/context integrations
- `ecs.*` and `aentity.*` ECS surfaces
- `atlas.*`, sprite, image, texture, and GUI support
- `epoch.*` higher-level engine/runtime entry surfaces that still intentionally brand the top-level API
