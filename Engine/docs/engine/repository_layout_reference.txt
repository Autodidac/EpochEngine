Not source authority / do not publish as source:
- x64/Debug and x64/Release: ordinary local MSBuild output and executable-local
  caches/logs. They are not proof of the published immutable release bytes.
- build/: disposable validation/compiler output; source-layout-20261007 holds
  isolated Debug/Release validation output without replacing the running Editor.
- Engine/bin, Engine/Bin, Engine/build, Engine/built: configured tool output.
- Projects/: user/generated project output. Keep the project source/assets you
  want; its intermediate build/cache data can be regenerated. Do not blanket-delete.
- Engine/examples/EpochEditor/workspace/cache/ai/iterations/session_*: private
  candidate source snapshots, build/evidence and succession state. Not canonical
  source. Do not remove an active candidate or chosen successor's retained parent.
- Explicit --candidate-data-root: private writable child state, not validated
  candidate code/build inputs. Path separation alone is not OS confinement.

Choose retains the tested sandbox successor as the next iteration's parent;
it does not overwrite canonical Engine source or the active project's source.
Keep retains the current parent. Source promotion is a separate reviewed action.
The repository's historical physical basename does not change these roles.
