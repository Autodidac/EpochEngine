# Epoch Changelog

## [v0.82.17]
- Consolidated the older versioned release-note markdowns into a single archive file so the `Changes/` folder keeps one historical notes surface while new releases continue to get their own markdown.
- Removed the accidentally tracked Windows `.exp` script-build artifact from the repo and added ignore rules for `.exp` files and the local `Temp Script Test/` workspace.
- Refreshed the active version surfaces to `v0.82.17`.

## [v0.82.16]
- Fixed the Windows editor script compiler path so it launches `clang++` directly instead of routing through a fragile shell command string that broke on `Program Files` paths.
- Kept the script source itself ASCII-clean and re-verified the rebuilt debug app launch from `x64/Debug` after the compiler-path fix.

## [v0.82.15]
- Replaced the old filewatch-oriented editor scripting flow with an engine-owned `Run` path that compiles and executes scripts against a stable host API, and swapped the default editor script to `rotate_all_entities`.
- Added reusable shared preview cameras with `Editor` and `FPS` modes, keyboard movement, and right-mouse look so the multicontext editor scene is no longer stuck on a fixed preview angle.
- Hardened updater version parsing so remote checks can consume either plain semver text or the full `aengine.version.ixx` module without printing BOM/comment garbage, then refreshed the active README/docs/version surfaces to v0.82.15.

## [v0.82.14]
- Rewrote the active README opening and feature map so Epoch is described more accurately as a world-class, modules-first, AI-enabled engine instead of a minimal runtime summary.
- Expanded the public feature list to call out internalized engine bootstrap, entry-point flexibility, multi-context orchestration, cross-platform build/editor freedom, module-first architecture, task-graph scripting reload, telemetry, and updater plumbing.
- Added direct markdown links from the README to the active docs, build surfaces, scripts, and project files, then refreshed the active version metadata to v0.82.14.

## [v0.82.13]
- Aligned the active backend base clear color to the darker Vulkan-style palette so mixed-context launches feel more like one engine instead of six unrelated demos.
- Moved SFML ahead of Vulkan in the default parented dock order and fixed the SFML shared scene preview so its grid/3D view stays clipped to the scene viewport instead of bleeding through GUI space.
- Rebuilt `StaticLib1` and `ConsoleApplication1` in `Debug|x64`, launched the real binary from `x64/Debug`, and verified the live top row now orders Raylib, SDL, and SFML ahead of Vulkan.

## [v0.82.12]
- Split the old mixed editor/menu flow into a launcher-first workflow where projects and games are chosen from the launcher and the editor focuses on desktop-style file, edit, scene, command, and help menus.
- Added scene preview switching in the editor between `Editor` and `None`, and gated the in-app update action behind an explicit confirmation modal because it can replace binaries and restart the session.
- Rebuilt `ConsoleApplication1` in `Debug|x64`, launched the real binary from `x64/Debug`, and refreshed the active README/docs to match the new launcher/editor workflow.

## [v0.82.11]
- Fixed parent-host shutdown ownership so only panes still docked under `EpochParent` close with the host, while undocked SDL, Raylib, and SFML panes survive as independent top-level windows.
- Fixed the last-window shutdown path so the process now exits when the final surviving undocked pane closes, even when that backend window is owned by a render thread.
- Re-verified live undock/redock and parent-close behavior on SDL, Raylib, and SFML, then refreshed the active README and current docs for the current engine tree.

## [v0.82.10]
- Restored real manual dock/undock interaction without the temporary `Alt` requirement by using a dedicated pane drag strip instead of hijacking the whole content surface.
- Re-verified live left-drag undock/redock behavior across SDL, Raylib, SFML, OpenGL, and Software, and confirmed the parent host still closes the full session cleanly afterward.
- Refreshed the active README and current docs to advertise the v0.82.10 manual docking interaction repair.

## [v0.82.9]
- Restored live undock/redock behavior by preserving each pane's original dock parent across future drags instead of forgetting it once a pane becomes top-level.
- Changed the docking grid arranger to lay out only panes that are currently parented under the live `EpochParent`, so undocked windows stop stealing grid slots or snapping back unexpectedly.
- Re-verified SDL, Raylib, SFML, OpenGL, and Software with live undock/redock interaction runs, then confirmed the parent host still closes the whole session cleanly.

## [v0.82.8]
- Fixed the parent-window shutdown path so docked backend panes close in place instead of being undocked during host shutdown.
- Re-verified that the parented multi-context layout stays docked at runtime and the process still exits when the main `EpochParent` host closes.
- Refreshed the active README and current docs to advertise the v0.82.8 docking/shutdown hotfix without rewriting historical release files.

## [v0.82.7]
- Hardened the parent-window close path so all tracked docked contexts receive shutdown and the engine session exits cleanly when the main host closes.
- Restored backend confirmation logging behind configurable `EPOCH_ENABLE_*CONFIRMATION_LOGS` switches so startup, upload, and teardown confirmations can be enabled without reintroducing per-frame spam.
- Refreshed the active README and current docs to advertise the v0.82.7 shutdown and diagnostics pass while keeping historical release files intact.

## [v0.82.6]
- Added the shared editor preview grid to the SDL and Software backends so they present the same scene-view framing as the existing GPU preview paths.
- Stopped the parented Raylib backend from replacing the original WGL device context after initialization, which stabilizes mixed-context startup.
- Refreshed the active README and current docs to advertise the v0.82.6 backend parity/stability pass without rewriting historical release files.

## [v0.82.5]
- Removed the unconditional per-frame Vulkan runtime diagnostic trace from normal runs and left it behind an explicit debug macro.
- Throttled slow-frame renderer warnings so startup no longer floods `Renderer.log` while the backend grid spins up.
- Removed the hot-loop SFML "frame render path" logging that was bloating `SFML.log` during startup.
- Refreshed the README and docs so the active build surfaces now cover Visual Studio, MSBuild, CMake presets, VS Code, shell scripts, and binary-folder launch paths.

## [v0.82.4]
- Restored the Vulkan editor scene pass so the backend renders the grid preview instead of only clearing the scene viewport.
- Matched the Vulkan editor preview framing and palette more closely to the OpenGL editor view, including calmer scene/background behavior during mixed-backend runs.
- Hardened the SFML close path so GPU atlas cleanup happens while the context is still valid and mixed-context shutdown stays quiet.

## [v0.82.3]

- Refreshed the active release surfaces and notes to advertise the v0.82.3 Vulkan preview update without rewriting historical release files.
