# Epoch Changelog

## [v0.82.0]
- Rebranded the public documentation and release metadata from the previous public name to Epoch.
- Synchronized engine version helpers and the legacy compatibility version header to v0.82.0.
- Moved the standalone `legacy/` archive into `Engine/legacy/` and added a single in-engine legacy archive guide.
- Rewrote the README, docs index, build guides, configuration guide, engine analysis, context audit, and runtime notes to match the current repository layout and backend status.

## [v0.81.23]
- Bumped the engine version constants to v0.81.23 so runtime banners and tooling remain aligned.
- Refreshed the README snapshot, configuration guide, and engine analysis notes to advertise the v0.81.23 release tag.
- Added the v0.81.23 release notes to keep the published metadata in sync.
- Documented the C++23 module-first baseline so build tooling and packagers can align module scanning and compiler expectations.

## [v0.72.9]
- Bumped the engine version constants and legacy headers to v0.72.9 so runtime banners and tooling remain aligned.
- Refreshed the README snapshot, configuration guide, and engine analysis notes to advertise the v0.72.9 release tag.
- Added the v0.72.9 release notes to keep the published metadata in sync.

## [v0.72.8]
- Converted additional legacy headers into module partitions so atlas utilities (`aatlasmanager.hpp`, `aatlastexture.hpp`) now expose `import aatlas.manager;` / `import aatlas.texture;`, the CLI surface is mirrored via `import acommandline;`, ECS mirrors (`import aentity.*`) stay in sync, and umbrella aggregates mirror the legacy include surface.
- Synced version metadata and documentation to advertise v0.72.8 with the refreshed import surface.
- Confirmed updater/configuration guidance pulls version strings from the runtime helpers so launch manifests match v0.72.8.

## Older releases
- Historical release notes remain in `Changes/release_notes_v*.md`.
- The older pre-rebrand release history has been preserved, but the public docs now use Epoch branding consistently.
