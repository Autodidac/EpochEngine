# Epoch Changelog

## [v0.82.33]
- Rolled the active repo surfaces forward after the packaged `0.82.32` release so `main` stays ahead of the downloadable runtime again.

## [v0.82.32]
- Reworked updater version probes to download into unique temp files instead of a shared `remote_version.txt`, preventing file-in-use failures when packaged and source checks run back to back.
- Kept the source-update availability messaging separate from packaged-release detection so the updater can point at `main` cleanly without confusing the release path.
- Cleaned the editor update confirmation modal spacing and trimmed the README snapshot back to a concise current-state summary.

## [v0.82.31]
- Rolled the active version and docs forward to `v0.82.31` immediately after the `0.82.30` updater rebuild release so the live tree stays ahead of the packaged runtime again.

## [v0.82.30]
- Restored the source-update flow so it now downloads the latest `main` snapshot, restores manifest dependencies with `vcpkg`, rebuilds `ConsoleApplication1`, and replaces the running runtime from the rebuilt output instead of stopping after extraction.
- Fixed updater version comparison so builds newer than the latest packaged release stop trying to downgrade themselves.
- Normalized updater console line emission for redirected output so captured update logs stop leaking raw CR/LF control glyphs.

## [v0.82.29]
- Rolled the active version and docs forward to `v0.82.29` immediately after the `0.82.28` update-flow release so the live tree stays ahead of the packaged runtime again.

- Added a source-snapshot command that downloads the latest `main` source tree beside the runtime without rebuilding or replacing the running binary.

- Added explicit failure reporting for update handoff/install failures so the app no longer looks like it updated successfully when the binary download or replacement step did not complete.
- Refreshed the active version surfaces to `v0.82.19`.

## [v0.82.18]

- Refreshed the active version surfaces to `v0.82.18`.

## [v0.82.17]

- Removed the accidentally tracked Windows `.exp` script-build artifact from the repo and added ignore rules for `.exp` files and the local `Temp Script Test/` workspace.
- Refreshed the active version surfaces to `v0.82.17`.

## [v0.82.16]
- Fixed the Windows editor script compiler path so it launches `clang++` directly instead of routing through a fragile shell command string that broke on `Program Files` paths.
- Kept the script source itself ASCII-clean and re-verified the rebuilt debug app launch from `x64/Debug` after the compiler-path fix.

## [v0.82.15]
- Replaced the old filewatch-oriented editor scripting flow with an engine-owned `Run` path that compiles and executes scripts against a stable host API, and swapped the default editor script to `rotate_all_entities`.
- Added reusable shared preview cameras with `Editor` and `FPS` modes, keyboard movement, and right-mouse look so the multicontext editor scene is no longer stuck on a fixed preview angle.
- Hardened updater version parsing so remote checks can consume either plain semver text or the full `aengine.version.ixx` module without printing BOM/comment garbage, then refreshed the active README/docs/version surfaces to v0.82.15.

## [v0.82.14]
- Rewrote the active README opening and feature map so Epoch is described more accurately as a world-class, modules-first, AI-enabled engine instead of a minimal runtime summary.
- Expanded the public feature list to call out internalized engine bootstrap, entry-point flexibility, multi-context orchestration, cross-platform build/editor freedom, module-first architecture, task-graph scripting reload, telemetry, and updater plumbing.
- Added direct markdown links from the README to the active docs, build surfaces, scripts, and project files, then refreshed the active version metadata to v0.82.14.

## [v0.82.13]
- Aligned the active backend base clear color to the darker Vulkan-style palette so mixed-context launches feel more like one engine instead of six unrelated demos.
- Moved SFML ahead of Vulkan in the default parented dock order and fixed the SFML shared scene preview so its grid/3D view stays clipped to the scene viewport instead of bleeding through GUI space.
- Rebuilt `StaticLib1` and `ConsoleApplication1` in `Debug|x64`, launched the real binary from `x64/Debug`, and verified the live top row now orders Raylib, SDL, and SFML ahead of Vulkan.

## [v0.82.12]
- Split the old mixed editor/menu flow into a launcher-first workflow where projects and games are chosen from the launcher and the editor focuses on desktop-style file, edit, scene, command, and help menus.
- Added scene preview switching in the editor between `Editor` and `None`, and gated the in-app update action behind an explicit confirmation modal because it can replace binaries and restart the session.
- Rebuilt `ConsoleApplication1` in `Debug|x64`, launched the real binary from `x64/Debug`, and refreshed the active README/docs to match the new launcher/editor workflow.

## [v0.82.11]
- Fixed parent-host shutdown ownership so only panes still docked under `EpochParent` close with the host, while undocked SDL, Raylib, and SFML panes survive as independent top-level windows.
- Fixed the last-window shutdown path so the process now exits when the final surviving undocked pane closes, even when that backend window is owned by a render thread.
- Re-verified live undock/redock and parent-close behavior on SDL, Raylib, and SFML, then refreshed the active README and current docs for the current engine tree.
