# EpochEngine v0.90.04 - Self-Coding UI And Fresh-Sandbox Reliability

- Fresh Candidate Lab sandboxes remain physically empty until source materialization completes.
- Self-iteration analytics are buffered in memory before materialization and flushed only after the copied workspace is ready.
- Qwen3.8 27B is the default local self-coding model.
- Live self-coding statistics are grouped together; source and sandbox paths are technical details.
- The session timer and workflow/model progress graphics remain visible during active work.
- Multiline EpochGui edit boxes soft-wrap instead of horizontally disappearing beyond the control.

The analytics schema remains predictor-ready for later EngCoder/JEV integration but does not control acceptance or safety in this version.
