full byte-budgeted inventory, supports create/reconcile/arrange groups and retains
actual question/answer history. One complete displayed plan requires one explicit
Apply. Applied/satisfied goals pause for explicit Next Plan. There is no arbitrary
256-call or 24-milestone lifetime quota; finite reply bytes, canonical resident
capacity, approved semantic tools and stale-result/rollback guards still apply.

scheduler. Group transactions adapt from 32 items toward an 8 ms measured worker

not GPU/frame-time telemetry, a strict indivisible-transaction deadline or
unbounded simultaneous resident objects. No silent reduction of requested counts.
